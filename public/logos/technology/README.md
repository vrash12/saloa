# Technology logos

The toolkit section uses locally hosted SVG marks for technologies where an official open-source icon was available. Logos are informational identifiers and do not imply endorsement.

- Devicon SVGs are pinned to commit `7330accdbc47e2dc0c19789a48533c4a3c50fe58` and covered by `DEVICON-LICENSE.txt`.
- OpenAI, Claude, Drizzle, Figma, Google Cloud, Supabase, Tailwind CSS, TypeScript, Next.js, PostgreSQL, Vue.js, and CSS3 assets were carried from the existing portfolio's curated logo set. Their source notes are preserved in the portfolio repository's `CREDITS.md` and `SIMPLE-ICONS-LICENSE.md`.
- All SVGs are served from this Site's `public/logos/technology/` directory; there are no runtime requests to an image CDN.
